# Fonte: GNU Unifont

`unifont-subset.hex` é um subconjunto do **GNU Unifont 17.0.05**
(https://unifoundry.com/unifont/, distribuído pelo projeto GNU em
https://ftp.gnu.org/gnu/unifont/).

Licença: GNU GPL versão 2 ou posterior, com a exceção para embutir fontes,
ou, alternativamente, SIL Open Font License 1.1.

Faixas incluídas: ASCII e Latin-1 (acentos do português), Latin Extended-A,
pontuação geral, setas, molduras e blocos, e alguns símbolos matemáticos.

O arquivo é convertido em uma tabela C durante a compilação por
`tools/unifont2c.py`.
